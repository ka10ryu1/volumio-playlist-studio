# 音響特徴量

`features.py` で librosa を使って抽出する特徴量と、その使い方をまとめる。抽出方法を変えた場合は `config.ANALYSIS_VERSION` を更新する。

## 解析する区間

曲全体を読むと時間がかかるため、次の方法で区間を切り出す（パラメータは設定画面で変更できる）。

1. 曲の先頭と末尾から `edge_margin_ratio`（既定 10%）を除く。イントロ・アウトロ・曲間の無音に特徴量が偏るのを防ぐ
2. 残りの範囲を `segment_count`（既定 3）等分し、それぞれの中央から `segment_seconds`（既定 20 秒）を切り出す
3. 区間全体の RMS が `silence_threshold_db`（既定 -60 dBFS）未満の区間は無音として除外する。フレームごとの dB の平均は無音フレームに引きずられて小さくなるため、線形の RMS で判定する
4. 除外後の範囲が足りない短い曲は、除外後の範囲全体を 1 区間として使う。2 秒未満の曲や、すべての区間が無音の曲はエラーとして記録する

フレーム単位の値は全区間をつなげて平均・標準偏差を求め、区間ごとの値（テンポ、平均音量）は区間どうしのばらつきを「時間的変動」として記録する。音声は 22,050 Hz・モノラルに変換してから解析する。

## 特徴量の一覧

| 特徴量（保存名） | 何を示すか | 分類への使い方 | 注意点 |
|---|---|---|---|
| 推定 BPM（`tempo_bpm`） | 発音の強さの周期から推定したテンポ（区間ごとの中央値） | エネルギー感・パーティー向けの判断材料の 1 つ | 実際の半分や倍に推定されることがある。BPM だけで「明るい」「元気」とは判断しない |
| テンポの変動（`tempo_variation`） | 区間ごとのテンポの変動係数 | 作業 BGM 向けか（テンポが安定しているか） | 区間が 1 つの場合は 0 |
| RMS Energy（`rms_mean_db`, `rms_std_db`） | 音量（フレームごとの RMS を dBFS にした値の平均と標準偏差） | エネルギー感、リラックス度 | マスタリングの音圧の影響が大きい。小さいだけで「リラックス向け」とは判断しない |
| 音量の時間的変動（`loudness_variation_db`） | 区間ごとの平均音量のばらつき | 穏やかさ・作業 BGM 向けか（盛り上がりの差が大きいか） | 区間数が少ないと不安定 |
| Spectral Centroid（`spectral_centroid_mean_hz`, `_std_hz`） | スペクトルの重心。高いほど高音成分が多く、音色が明るく鋭い | エネルギー感、夜の BGM 向けか | 音色の明るさであり、曲調の明暗（長調・短調）ではない |
| Spectral Rolloff（`spectral_rolloff_mean_hz`） | エネルギーの 85% が含まれる上限の周波数 | Centroid と合わせて音色の明るさ | 録音の帯域（ビットレート）の影響を受ける |
| Zero Crossing Rate（`zero_crossing_rate_mean`） | 波形が 0 をまたぐ頻度。雑音・打楽器・歪んだ音で高い | 穏やかさ（滑らかな音か） | 高音の楽器でも高くなる |
| Onset Strength（`onset_strength_mean`, `_std`） | 音の立ち上がりの強さ | 打楽器的か、アタックが強いか | 値の尺度は音源に依存する |
| 発音の頻度（`onset_rate_per_sec`） | 1 秒あたりの発音（オンセット）の数 | エネルギー感、リズムの密度 | 持続音中心の曲では少なく出る |
| Chroma（`chroma_mean`） | 12 の音名ごとのエネルギーの平均 | 現在は保存のみ。将来、調性の推定に使う可能性がある | チューニングの推定は行わず A4 = 440 Hz を前提にする。調の判定は単純な平均では信頼できない |
| MFCC（`mfcc_mean`, `mfcc_std`） | 音色の特徴（13 次元） | 現在は保存のみ。将来、類似曲の検索や学習ベースの分類に使う可能性がある | 次元ごとの意味を言葉で解釈しにくいため、Jev には渡さない |

## ルールベース分類での使い方

`classify/rules.py` では、単一の特徴量で属性を断定しないよう、各属性を複数の特徴量を 0〜1 に正規化した値の平均で求める。正規化の範囲は `config.RuleParameters`（一般的なポピュラー音楽を目安にした初期値）。

| 属性 | 計算 |
|---|---|
| エネルギー感 | 平均（音量、テンポ、発音の頻度、音色の明るさ） |
| リラックス度 | 平均（1 − 音量、1 − 発音の頻度、1 − 音色の明るさ、1 − 音量の変動） |
| 穏やかさ | 平均（1 − 発音の頻度、1 − 音量の変動、1 − ゼロ交差率） |
| 作業 BGM 適性 | 平均（エネルギー感が 0.4 に近いほど高い値、1 − 音量の変動、テンポの安定性） |
| パーティー・運動向け | 平均（音量、テンポ、発音の頻度） |
| 夜の BGM 適性 | 平均（リラックス度、穏やかさ、1 − 音色の明るさ） |
| 明るさ（曲調） | 判定保留（調性・和声の判定が必要で、基本的な特徴量からは信頼できる値を出せない） |

ジャンルはタグのジャンル表記だけから決め、当てはまらない場合は不明とする。歌詞の内容やボーカルの有無は判定しない。
