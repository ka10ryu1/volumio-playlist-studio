# リリースノート

利用者から見える変更（新機能、画面の変更、利用者に影響する不具合の修正）を、PR ごとに新しい順に記録します。アプリの「リリースノート」画面にも同じ内容を表示します。開発用のツール・テスト・CI だけの変更は載せていません。

項目は `## <マージ日（YYYY-MM-DD）> #<PR 番号> <見出し>` の行で始め、次の項目までを詳しい説明として書きます（説明の中で見出しを使う場合は `###` 以下にします）。曲名・アーティスト名など、利用者固有のデータは書きません。

## 2026-11-26 #63 確認用レポートに、人手の評価と比べた Jev のムードの偏りを追加

設定画面の確認用レポートに、精度評価でムードの正解を入力した曲について、Jev とルールベースのムードの判定を正解と比べた集計を追加しました。Jev のムードが「元気」に偏る原因を調べるためのものです。

集計するのは調整用の曲だけです。検証用の曲は、判定の仕組みを直した後に効果を確かめるために残しておき、件数だけを表示します。

- 正解のムードと判定したムードの対応表（Jev・ルールベースそれぞれ）
- 正解と Jev の判定の組ごとに、ムードの適合度、属性の値（Jev・ルールベース・人手の 5 段階評価）、Jev の属性ごとの各段階の確率の平均

リラックスと穏やかな夜の取り違えは、人でも区別に迷うため誤りに含めていません。保存済みの結果から集計するため、Jev の料金はかかりません。曲名などは含めず、件数と平均だけを出します。

## 2026-11-26 #62 プレイリスト作成で曲の試聴と、理由を選んだ除外ができるように

プレイリスト作成画面の「2. 曲を編集」で、曲一覧の各曲に「再生」「ジャンル違い」「好みでない」のボタンを置きました。

- 「再生」を押すと、その曲を画面を開いている端末（PC・スマートフォン）のブラウザで再生できます。曲名だけでは分からないときに確かめられます。Volumio では再生せず、Volumio の再生状態は変わりません。ブラウザが対応していない形式は再生できないことがあります
- 「ジャンル違い」「好みでない」を押すと、1 回の操作でその曲をプレイリストから除外します。これまでのように曲を選んでから「除外」を押す必要はありません（曲順の入れ替えは「並べ替える曲」で選んで「上へ」「下へ」を押します）
- 除外の理由は評価データとして記録します。「ジャンル違い」は分類の誤りとして、精度評価画面の「プレイリスト」タブに分類結果の種類・ジャンルごとの件数を表示します。「好みでない」は記録するだけで、次回以降の選曲には影響しません
